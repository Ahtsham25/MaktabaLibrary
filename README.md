# مکتبۃ العلماء — Maktaba Library (Shami Academy)

171 مکتبے، 5422 کتابیں — Internet Archive سے، آف لائن ڈاؤن لوڈ اور آن لائن مطالعہ دونوں سہولتوں کے ساتھ۔

## GitHub پر سیٹ اپ کرنے کا طریقہ (github.dev استعمال کرتے ہوئے)

1. اس پورے فولڈر کو ایک نئی GitHub repository میں اپلوڈ کریں (github.dev کے ذریعے فائل بہ فائل، یا اگر کبھی کمپیوٹر ملے تو ایک ساتھ)۔

2. **ضروری قدم:** فائل
   `app/src/main/java/com/shamiacademy/maktabalibrary/data/LibraryRepository.kt`
   کھولیں اور یہ لائن:
   ```
   private const val RAW_JSON_URL =
       "https://raw.githubusercontent.com/REPLACE_ME/REPLACE_ME/main/data/authors.json"
   ```
   کو اپنے اصل ریپو کے مطابق تبدیل کریں، مثلاً:
   ```
   "https://raw.githubusercontent.com/shaukat-alii/maktaba-library/main/data/authors.json"
   ```

3. `data/authors.json` بھی اسی ریپو میں `main` برانچ پر رہنی چاہیے — یہی ایپ کا ڈیٹا بیک اینڈ ہے۔ نئی کتاب/مکتبہ شامل کرنا ہو تو صرف اسی فائل میں اندراج بڑھائیں، ایپ دوبارہ بنانے کی ضرورت نہیں۔

4. `main` برانچ پر پش ہوتے ہی GitHub Actions (`.github/workflows/build.yml`) خودکار طور پر Gradle 8.4 سے APK بنائے گا۔ نتیجہ "Actions" ٹیب میں "maktaba-library-debug-apk" کے نام سے ملے گا۔

## اہم فیچرز

- **کتابیں ٹیب:** تمام 5422 کتابیں، سرچ کے ساتھ
- **مصنفین ٹیب:** 171 مکتبے، ہر ایک پر کلک سے اس کی تمام کتابیں
- **ڈاؤن لوڈز ٹیب:** ڈاؤن لوڈ شدہ کتابیں، آف لائن ان-ایپ PDF ریڈر کے ساتھ (نیلا ٹک نشان)
- **مزید ٹیب:** پرائیویسی پالیسی، ڈسکلیمر، تعارف، رابطہ
- کتاب کارڈ کا تھمب نیل: ڈاؤن لوڈ ہونے کے بعد خودکار طور پر اسی کتاب کے پہلے صفحے سے بنتا ہے (PdfRenderer)؛ اس سے پہلے مکتبے کی مشترکہ تصویر دکھائی جاتی ہے
- تھیم: کالا پس منظر + سنہری نور طرز کا بارڈر
- اسپلاش اسکرین: مسجد نبوی طرز کا اصل (originally-drawn) لوگو

## معلوم حدود

- کتابوں کے عنوان فی الحال رومن اردو میں ہیں (فائل ناموں سے صاف کیے گئے)، چونکہ 5422 کتابوں کے مکمل اصلی اردو عنوان دستی طور پر لکھنا ممکن نہیں تھا
- ہر کتاب کی اپنی الگ تھمب نیل صرف ڈاؤن لوڈ ہونے کے بعد بنتی ہے (Android کا PdfRenderer صرف مکمل لوکل فائل پر کام کرتا ہے)؛ اس سے پہلے مکتبے کی مشترکہ کور تصویر دکھتی ہے
